Routing tree

Set the top-level dimensions and their sub-dimensions. Routers route to their children, and leaves hold the chunks. Each node's description is what the router matches a query against.

Stores

    The tree has 3 levels, 3 routers and 7 leaves. All 7 leaves are reached when beam is 3, so routing does not narrow the search at that setting. See eval.

    Sources API gap

    Choose where each leaf's documents come from. Converting files to text is done by a separate service, mlx-ingestion-backend, or a future Rust replacement. strata only receives text.
